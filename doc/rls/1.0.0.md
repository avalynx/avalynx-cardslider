## Release 1.0.0 – Changelog Summary

Version 1.0.0 marks the initial public release of **AvalynxCardSlider**, introducing a lightweight, dependency-free card slider designed specifically for the Bootstrap grid system. It enables responsive, column-based sliding behavior while keeping the native Bootstrap layout intact.

* **Core Card Slider Component**
Introduces a lightweight JavaScript slider built around the Bootstrap grid system (≥5.3).
Allows developers to transform standard Bootstrap card layouts into responsive sliders without additional frameworks.

* **Bootstrap Grid Integration**
Uses native Bootstrap column classes such as `col-12`, `col-md-6`, or `col-lg-4`.
Ensures that responsive breakpoints and layout behavior work seamlessly with the slider.

* **Flexible Scroll Modes**
Provides two scrolling behaviors: `single` (move one card per click) and `page` (advance by the number of currently visible cards).
Enables different UX patterns depending on the content layout.

* **Automatic Placeholder Handling in Page Mode**
When the last page contains fewer cards than the grid layout expects, placeholder items are automatically generated.
Maintains visual consistency and prevents layout gaps.

* **Navigation Controls & Pagination Dots**
Supports optional Next/Previous buttons and automatically generated pagination dots.
Allows flexible placement of controls inside or outside the slider container.

* **Performance-Focused Implementation**
Built with modern ES6 and minimal CSS.
Includes debounced resize handling to keep scrolling calculations efficient and responsive.

* **Flexible Integration Options**
Can be installed via CDN, NPM, Composer, Symfony AssetMapper, or AssetComposer.
Makes the component easy to integrate into modern JavaScript or PHP-based workflows.

* **Comprehensive Examples & Documentation**
Includes multiple demo pages covering different scroll modes, alignment options, and complex card layouts.
Helps developers quickly understand usage and integration patterns.
**Compatibility**: Initial release
